# Evidências da Sprint 1

Execute o sistema com `scripts/start-agencies.ps1` e depois rode `scripts/validar-sprint1.ps1`.
O segundo script faz chamadas reais às três instâncias, reproduz a falha conhecida, executa os testes automatizados e grava nesta pasta respostas datadas para cada item avaliado.

Os arquivos de evidência são regeneráveis e não foram preenchidos com resultados simulados.
